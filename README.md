# Student Performance Prediction Using CRISP-DM

## Overview

This project applies the **CRISP-DM methodology** to analyse a student performance dataset containing **1,240 records and 21 attributes**. The goal was to identify factors influencing academic success and build a machine learning model to predict whether a student would **Pass** or **Fail**.

## Key Activities

- Conducted **Business Understanding** and **Data Understanding**
- Performed **Exploratory Data Analysis (EDA)** using statistics and visualisations
- Investigated missing values, outliers, and data quality issues
- Built a **Decision Tree Classifier** as a baseline model
- Evaluated performance using **Accuracy, Precision, Recall, and F1-Score**
- Applied data preparation techniques including:
  - Missing value handling
  - Row and column removal
  - Univariate imputation
  - Outlier removal
- Performed **hyperparameter tuning** to improve model performance

## Results

- Baseline Decision Tree accuracy: **0.77**
- Best performing approach: **Mode Imputation for missing Modality values**
- Improved model accuracy to approximately **0.79**
- Found that data preparation had a greater impact on performance than hyperparameter tuning
